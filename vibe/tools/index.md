## バイブコーディングの2つの道具

AIにプログラムを作ってもらう道具には、大きく2つのタイプがあります。それぞれ得意・不得意があります。

<div class="tool-compare">
  <div class="card">
    <span class="tool-tag today">今日はこちら</span>
    <h3>対話システムの「Canvas」機能</h3>
    <p><strong>表面的な動き</strong>のあるものを、その場ですぐ作れます。ブラウザだけで完結し、パソコンの設定は不要です。一方で、データの保存や、他のサービスとの本格的な連携は難しいという弱点があります。</p>
    <p class="muted">例：ChatGPT・Gemini などの Canvas 機能</p>
  </div>
  <div class="card">
    <span class="tool-tag later">別の授業で</span>
    <h3>汎用プログラミングツール</h3>
    <p>開発できるシステムの<strong>自由度が高く</strong>、本格的なアプリやデータの保存もできます。そのぶん、使い始めるにはパソコンの設定（環境構築）が必要で、少しハードルが上がります。</p>
    <p class="muted">例：Claude Code など</p>
  </div>
</div>

## 作りたいものに合わせて選ぶ

どちらが優れているということではなく、**作りたいシステムに合わせて、適切なほうを選ぶ** ことが大切です。ちょっとしたアイデアを素早く形にして見せたいならCanvas、しっかりしたサービスを作り込みたいなら汎用プログラミングツール、というように使い分けます。
