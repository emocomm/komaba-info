## Googleスプレッドシートを新規作成

計算を始める前に、分析用のスプレッドシートを作ります。

[Googleスプレッドシート](https://sheets.google.com) にアクセスして、新規スプレッドシートを作成します。

## シートを3枚作る

下のタブで `+` ボタンを押してシートを追加し、シート名を次の3つに変更します。

- `カウント`
- `確率`
- `情報量`

この3枚のシートを、次の役割で使います。

| シート名   | 役割                                   |
| ---------- | -------------------------------------- |
| `カウント` | 文字ごとの出現回数を数える             |
| `確率`     | 出現回数を確率に変換する               |
| `情報量`   | `-p log₂ p` を計算し、平均情報量を出す |

## この演習の列配置

この演習では、パターンAとパターンBを同じ `カウント` シートに入れて計算します。

計算を始める前に、どの列に何を入れるかを決めておきます。ここをそろえておくと、あとで `カウント`、`確率`、`情報量` の3シートで同じ形の表として扱えます。

| 範囲   | 内容                      |
| ------ | ------------------------- |
| `A`    | 文字種マスター            |
| `B:H`  | パターンAの発話ごとの計算 |
| `I:N`  | パターンAの会話全体の計算 |
| `O:U`  | パターンBの発話ごとの計算 |
| `V:AA` | パターンBの会話全体の計算 |

`I:N` と `V:AA` は、このあと累積の計算を入れる列です。発話本文は入れません。

## この演習の行配置

次に、行の使い方を確認します。

| 行         | 内容                                                 |
| ---------- | ---------------------------------------------------- |
| 1行目      | 見出しを入れる                                       |
| 2行目      | 文章自体を入れる                                     |
| 3行目      | 何も入れない。見出し・本文と計算表を分けるための空行 |
| 4行目以降  | 文字ごとの出現数、確率、情報量を計算する             |
| 一番下の行 | 各列の合計を入れる                                   |

この教材では、文字種マスターと計算式を `4` 行目から入れます。一番下の合計行は、後の手順を経て `143` 行目になります。

## パターンAを貼り付ける

1. パターンAの7発話を1行ずつコピーする
2. [TSV変換ツール]({{ '/entropy/tsv/?from=sheet-design' | relative_url }}) を開く
3. 変換ツールに貼り付けて、横タブ区切りに変換する
4. 変換結果をコピーする
5. `カウント` シートを開く
6. `B2` セルを選択して貼り付ける
7. `B2:H2` に7発話が横に並べば成功

## パターンBを貼り付ける

同じ手順でパターンBも横タブ区切りに変換します。

変換結果をコピーしたら、`O2` セルを選択して貼り付けます。`O2:U2` に7発話が横に並べば成功です。
