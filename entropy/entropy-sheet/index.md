## このシートで何をするか

`情報量` シートでは、各文字について `-p log₂ p` を計算し、列ごとに合計して平均情報量を求めます。

## 準備: 文字一覧をA列に貼り付ける

`情報量` シートの `A4` セルにも、[文字種カウントツール]({{ '/entropy/count/?from=count-sheet' | relative_url }})で作成した文字一覧を貼り付けます。A列の文字の並び順が `カウント` シート、`確率` シートと同じになるようにしてください。

列配置も `カウント` シート、`確率` シートと同じです。

| 範囲   | 内容                            |
| ------ | ------------------------------- |
| `B:H`  | パターンAの発話ごとの平均情報量 |
| `I:N`  | パターンAの会話全体の平均情報量 |
| `O:U`  | パターンBの発話ごとの平均情報量 |
| `V:AA` | パターンBの会話全体の平均情報量 |

## 関数を入れる: 情報量への寄与

`B4` セルに次の関数を入れます。

<div class="code-copy">
  <pre><code>=IF(確率!B4=0, 0, -確率!B4*LOG(確率!B4, 2))</code></pre>
  <button type="button" class="small" data-copy="=IF(確率!B4=0, 0, -確率!B4*LOG(確率!B4, 2))">コピー</button>
</div>

この関数の意味は次のとおりです。

- 確率が `0` の場合は `0` にする
- 確率が `0` でない場合は `-p × log₂(p)` を計算する
- `LOG(0)` はエラーになるため、`IF` で回避する

## オートフィルで広げる

`B4` セルを選択して、`AA142` までオートフィルします。

## エントロピーを計算する

`B143` セルに次の関数を入れ、`AA143` まで横にオートフィルします。

<div class="code-copy">
  <pre><code>=SUM(B4:B142)</code></pre>
  <button type="button" class="small" data-copy="=SUM(B4:B142)">コピー</button>
</div>

`B143:AA143` に並ぶ数字が、平均情報量 `H` です。

- `B143:H143`: パターンAの発話ごとの平均情報量
- `I143:N143`: パターンAの会話全体の平均情報量
- `O143:U143`: パターンBの発話ごとの平均情報量
- `V143:AA143`: パターンBの会話全体の平均情報量

<img class="guide-image" src="{{ '/assets/images/entropy-sum.svg' | relative_url }}" alt="情報量シートのB143からAA143に平均情報量が並ぶ説明図">

## チェックポイント

パターンAの場合、次の値に近くなります。

| セル    | 意味                       | 参考値    |
| ------- | -------------------------- | --------- |
| `B143`  | パターンAの発話1のH        | 約 `4.35` |
| `N143`  | パターンAの発話1〜7全体のH | 約 `5.53` |
| `O143`  | パターンBの発話1のH        | 約 `4.32` |
| `AA143` | パターンBの発話1〜7全体のH | 約 `6.29` |
