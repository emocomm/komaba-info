## 正解値

句読点、半角空白、全角空白を除外して計算した場合の参考値です。

## シート内の列配置

この版では、パターンAとBを同じ3シート内で横方向に並べて計算します。

| 範囲 | 内容 |
|---|---|
| `B:H` | パターンAの発話ごと |
| `I:N` | パターンAの会話全体 |
| `O:U` | パターンBの発話ごと |
| `V:AA` | パターンBの会話全体 |

## 期待される観察

- 発話単独のHは、両パターンとも `4.0〜4.8 bit` 程度で揺れる
- 会話全体のHは、Aでは `5.5 bit` 付近で頭打ちに近づく
- 会話全体のHは、Bでは `6.3 bit` 付近まで伸び続ける
- Aでは「物件」「駅」など同じ字が繰り返される
- Bでは話題が変わり、新しい字種が登場し続ける

## 考察の評価目安

| レベル | 内容 |
|---|---|
| 1 | 数値やグラフの傾向を述べている |
| 2 | 話題の収束、拡散に触れている |
| 3 | 平均情報量が「分布に対する量」であることに触れている |
| 4 | 現実のコミュニケーションへの示唆まで踏み込んでいる |

## よくあるつまずきと対応

| つまずき | 確認すること |
|---|---|
| `H143` や `AA143` の値が変 | `カウント` シートの `$` の位置、文字一覧の貼り付け位置 |
| 確率の合計が1にならない | カウントの合計、参照シート名、`B$143` の固定 |
| `LOG` 関数がエラー | `IF` で確率0を回避できているか |
| 発話を縦に貼ってしまった | TSV変換ツールを使っているか、貼り付け先がAは `B2`、Bは `O2` か |

## 概念的な注意

この課題で計算しているのは、平均情報量を足し合わせたものではありません。観測範囲を広げたときに、平均情報量を計算し直した値です。

生徒が「累積エントロピー」という言葉に引っかかった場合は、「ここまでの会話全体を一つのテキストとみなしたときの平均情報量」と説明してください。
