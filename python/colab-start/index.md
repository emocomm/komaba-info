Google Colabを始めるには、以下の手順を参考にしてみてください。

1. ブラウザから[Google Colab](https://colab.research.google.com/)（[https://colab.research.google.com/](https://colab.research.google.com/)）のサイトにアクセスします。チュートリアルの画面が表示されるはずです。
2. 「ファイル」メニューから「ノートブックを新規作成」を選択します。すると新しいノートブックが開かれ、そこでPythonコードを書いて実行することができます。Googleアカウントでのサインインをしていない場合は、ここでサインインが求められます。サインインが求められた場合は、ECCSクラウドメール（`g.ecc.u-tokyo.ac.jp` で終わるメールアドレス）でサインインしてください。

<img class="guide-image" src="{{ '/assets/python/colab-new-notebook.png' | relative_url }}" alt="Google Colabでノートブックを新規作成">

{:start="3"}
3. 新しいノートブックが作成されて、自由にコードを書けるようになります。コードを書き終えたら、「Shift」キーと「Enter」キーを同時に押すとその行のコードが実行され、結果が下に表示されます。
