   3.1 /1 平均情報量の復習
   目的: 既習内容の呼び覚まし
   含めるコンテンツ:
   (見出し)平均情報量とは
   平均情報量(エントロピー)は、ある情報源から出てくる記号の「散らばり具合」を表す量です。式は次のとおり:
   H = -Σ p(x) log₂ p(x)

p(x) は記号 x が出る確率
単位は bit
全ての記号が等確率で出るとき H は最大、ある記号だけが出るとき H = 0

(見出し)直感的な例

「あああああああああ」(全部同じ)→ H = 0 bit
「あいうえおかきくけこ」(全部違う)→ H = log₂(10) ≈ 3.32 bit
散らばりが大きいほど H は大きい

(見出し)今回ぜひ覚えておいてほしいこと
平均情報量は、ある情報源(=記号の出方の分布)に対して 定義される量です。同じ文字列でも、どこからどこまでを「情報源」とみなすかによって平均情報量は変わります。これは後の課題で重要になります。
「もし思い出せなかったら、教科書 p.◯◯ を見直してください。」(教科書ページは教師が空欄に入れる)

(見出し)なぜやるのか
普段使っているチャットでも、会話の性質によって「情報の散らばり」が違う。それを数値で測れることを体験する。
(見出し)今回計算する2種類の平均情報量
今回の課題では、同じ会話に対して 2つの視点 で平均情報量を計算します。これが本課題の中心です。
視点1:発話ごとの平均情報量

「1つの発話だけを見たときに、その中の文字の散らばりはどれくらいか」
7発話あれば、7つのH値が出る

視点2:会話全体の平均情報量

「1発話目からn発話目までを ひとつのまとまった会話 とみなしたときに、その全体の文字の散らばりはどれくらいか」
観測範囲を1発話、2発話、3発話…と広げていく
7発話あれば、「1まで」「1-2」「1-3」…「1-7」と7つのH値が出る

なぜ2つ計算するのか

視点1だけだと、発話ごとの揺らぎは見えても、会話の全体的な傾向は見えにくい
視点2で見ると、会話が進むにつれて新しい文字が登場し続けるか/出尽くすかが見える
この2つを比べることで、会話の性質がわかる

(見出し)全体の流れ

javascriptfunction generateUniqueChars(text, excludePunct = true) {
const punctuation = new Set([
'、', '。', '?', '!', '?', '!', ' ', '　', '\n', '\r', '\t'
]);
const chars = new Set();
for (const ch of text) {
if (excludePunct && punctuation.has(ch)) continue;
chars.add(ch);
}
return Array.from(chars).sort();
}

3.6 /5 シート1「カウント」の作業
目的: 各発話における各文字の出現回数を計算
含めるコンテンツ:
(見出し)このシートで何をするか
「文字が何回出てきたかを数える」
進捗:●●●●○○○○○○ (4/10)
(見出し)準備:文字一覧をA列に貼り付ける
まだ文字一覧を生成していなければ → /count
カウントシートの A4 セルを選択 して、生成した文字一覧を貼り付け。A4から下に文字が縦に並ぶ(約140行)。
(見出し)関数を入れる:出現回数の計算
B4 セルに次の関数を入れる:
=LEN(B$2)-LEN(SUBSTITUTE(B$2,$A4,""))
[コピーボタン]
この関数の意味:

LEN(B$2):B2の発話の文字数
SUBSTITUTE(B$2, $A4, ""):B2の中からA4の文字を全部削除した文字列
引き算すれば「A4の文字が何個あったか」がわかる

なぜ B$2 と $A4 か:

B$2:B列を見るが、行は2のまま(下にコピーしても発話を見続ける)
$A4:A列を見るが、行は4から動かない(横にコピーしても文字を見続ける)

(見出し)オートフィルで広げる

B4セルを選択
右下の青い四角を H4までドラッグ (横方向)
B4〜H4を選択して、H142までドラッグ (下方向)
これで B4〜H142 の範囲に出現数が並ぶ

(見出し)合計を出す
B143 セルに次の関数を入れる:
=SUM(B4:B142)
[コピーボタン]
これをH143まで横にオートフィル。各列の合計 = その発話の総文字数(句読点除く)。
(見出し)チェックポイント
B143の数字が、B2の発話を句読点なしで数えた文字数と一致しているか確認:

例:発話1「引っ越し先の…」→ 28文字(句読点除く)になっているはず

合わなかったら:

句読点が文字一覧に含まれていないか確認(/countで除外設定を確認)
$の位置が間違っていないか確認
貼り付け位置がズレていないか確認

(見出し)視点2のために:会話全体の出現数を計算
I4 セルに次の関数を入れる:
=B4+C4
(発話1〜2の合計出現数)
J4 セルに:
=I4+D4
(発話1〜3の合計、I列に発話3を足す)
K4 セルに:=J4+E4 (発話1〜4)
L4 セルに:=K4+F4 (発話1〜5)
M4 セルに:=L4+G4 (発話1〜6)
N4 セルに:=M4+H4 (発話1〜7)
I4〜N4を選択して、142行までオートフィル。
143行目にも合計を入れる:=SUM(I4:I142) を I143 に、N143 まで横にオートフィル。
「これで、視点1(B〜H列)と視点2(I〜N列、累積)、両方の準備ができました。」
(見出し)よくあるつまずき

$マークの付け忘れ → 関数が崩れる
文字一覧の貼り付けがA4からでなくA5から → 1行ズレる
句読点が文字一覧に混入 → 余計なゼロ行ができる(動作はする)
発話本文を間違ってA列に貼ってしまう → 発話はB2:H2に貼る

4.2 検証用エントロピー計算
javascriptfunction calculateEntropy(text, excludeChars = ['、', '。', '?', '!', '?', '!', ' ', '　']) {
const exclude = new Set(excludeChars);
const counts = {};
let total = 0;

for (const ch of text) {
if (exclude.has(ch)) continue;
counts[ch] = (counts[ch] || 0) + 1;
total++;
}

if (total === 0) return 0;

let H = 0;
for (const ch in counts) {
const p = counts[ch] / total;
H -= p \* Math.log2(p);
}

return H;
}

1. 概念の3段階分解
