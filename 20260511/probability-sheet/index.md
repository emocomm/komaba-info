## このシートで何をするか

`確率` シートでは、`カウント` シートで数えた回数を確率 `p(x)` に変換します。

## 準備: 文字一覧をA列に貼り付ける

`確率` シートの `A4` セルにも、[文字種カウントツール]({{ '/20260511/count/?from=count-sheet' | relative_url }})で作成した文字一覧を貼り付けます。A列の文字の並び順が `カウント` シートと同じになるようにしてください。

列配置も `カウント` シートと同じです。

| 範囲   | 内容                      |
| ------ | ------------------------- |
| `B:H`  | パターンAの発話ごとの確率 |
| `I:N`  | パターンAの会話全体の確率 |
| `O:U`  | パターンBの発話ごとの確率 |
| `V:AA` | パターンBの会話全体の確率 |

## 関数を入れる: 確率の計算

`B4` セルに次の関数を入れます。

<div class="code-copy">
  <pre><code>=カウント!B4/カウント!B$143</code></pre>
  <button type="button" class="small" data-copy="=カウント!B4/カウント!B$143">コピー</button>
</div>

この関数は、`カウント` シートの `B4` の出現数を、`B143` の総文字数で割っています。

## オートフィルで広げる

`B4` セルを選択して、`AA142` までオートフィルします。これで、`B4:AA142` に各文字の確率が並びます。

<img class="guide-image" src="{{ '/assets/images/probability-autofill.svg' | relative_url }}" alt="確率シートでB4に式を入れてAA142までオートフィルする説明図">

## 合計を確認する

`B143` に次の関数を入れ、`AA143` まで横にオートフィルします。

<div class="code-copy">
  <pre><code>=SUM(B4:B142)</code></pre>
  <button type="button" class="small" data-copy="=SUM(B4:B142)">コピー</button>
</div>

`B143:AA143` の数字がすべて `1`、または `1.000` になっていれば正解です。

<img class="guide-image" src="{{ '/assets/images/probability-sum.svg' | relative_url }}" alt="確率シートのB143からAA143が1.000になることを確認する説明図">

## なぜ合計が1になるのか

確率は「全体に対する割合」です。すべての文字の確率を足すと、全体の割合になるため `1` になります。

## うまくいかないとき

- `カウント` シートの合計行が正しいか確認する
- シート名が `カウント` になっているか確認する
- `B$143` の `$` が抜けていないか確認する

確率が `0` のセルは、「その文字がその発話に出てこなかった」という意味です。
