## 使う関数

| 関数 | 機能 | 例 |
|---|---|---|
| `LEN(文字列)` | 文字列の長さを返す | `LEN("こんにちは")` → `5` |
| `SUBSTITUTE(文字列, 検索文字, 置換文字)` | 検索文字を置換する | `SUBSTITUTE("ababa", "a", "")` → `bb` |
| `LOG(数値, 底)` | 対数を計算する | `LOG(8, 2)` → `3` |
| `SUM(範囲)` | 範囲の合計を出す | `SUM(B4:B142)` |
| `IF(条件, 真の場合, 偽の場合)` | 条件で処理を分ける | `IF(A1=0, 0, 1/A1)` |

## 他シートの参照

別のシートのセルを参照するには、シート名の後に `!` を付けます。

<div class="code-copy">
  <pre><code>=カウント!B4</code></pre>
  <button type="button" class="small" data-copy="=カウント!B4">コピー</button>
</div>

これは、`カウント` シートの `B4` セルの値を取得するという意味です。

## 絶対参照と相対参照

セル番地に `$` を付けると、コピーしてもその部分が動かなくなります。

| 書き方 | 意味 |
|---|---|
| `B4` | 縦にも横にも動く |
| `$B4` | 横にコピーしても列Bのまま |
| `B$4` | 下にコピーしても行4のまま |
| `$B$4` | 列も行も固定 |

## オートフィル

セルを選択して右下の小さい四角をドラッグすると、関数を自動でコピーできます。今回の作業では、これを横方向・下方向に何度も使います。
