## 2つのグラフを作る

最初に予告した2つの視点を、ここで比較します。

## グラフ1: 発話ごとの平均情報量

作るものは、発話ごとの `H` を示す棒グラフです。パターンAとパターンBを同じグラフで比べます。

別のシート、または情報量シートの空いている場所に、次のような表を作ります。

| 発話 | パターンA      | パターンB      |
| ---- | -------------- | -------------- |
| 1    | `=情報量!B143` | `=情報量!O143` |
| 2    | `=情報量!C143` | `=情報量!P143` |
| 3    | `=情報量!D143` | `=情報量!Q143` |
| 4    | `=情報量!E143` | `=情報量!R143` |
| 5    | `=情報量!F143` | `=情報量!S143` |
| 6    | `=情報量!G143` | `=情報量!T143` |
| 7    | `=情報量!H143` | `=情報量!U143` |

1. 作った表を選択する
2. 上部メニューの `挿入` → `グラフ` を選ぶ
3. グラフの種類を `縦棒グラフ` にする
4. 横軸ラベルを発話番号 `1〜7` にする
5. 縦軸ラベルを `H (bit)` にする

縦軸の範囲は、最小値を `0`、最大値を `5` にすると比較しやすくなります。

## グラフ2: 会話全体の平均情報量

作るものは、観測範囲を広げたときの `H` を示す折れ線グラフです。パターンAとBを同じグラフに重ねます。

別のシート、または情報量シートの空いている場所に、次のような表を作ります。

| 範囲  | パターンA      | パターンB       |
| ----- | -------------- | --------------- |
| 1まで | `=情報量!B143` | `=情報量!O143`  |
| 1-2   | `=情報量!I143` | `=情報量!V143`  |
| 1-3   | `=情報量!J143` | `=情報量!W143`  |
| 1-4   | `=情報量!K143` | `=情報量!X143`  |
| 1-5   | `=情報量!L143` | `=情報量!Y143`  |
| 1-6   | `=情報量!M143` | `=情報量!Z143`  |
| 1-7   | `=情報量!N143` | `=情報量!AA143` |

この表を選択して、`挿入` → `グラフ` → `折れ線グラフ` を選びます。
