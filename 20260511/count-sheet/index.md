## このシートで何をするか

`カウント` シートでは、パターンAとパターンBの両方について、文字ごとの出現回数を計算します。

## 準備: 文字種マスターを作る

これから作る表では、縦方向に「調べる文字」、横方向に「発話」を並べます。

たとえば `A4` に「駅」が入っていれば、`B4` では発話1に「駅」が何回出たか、`C4` では発話2に「駅」が何回出たかを数えます。つまり、A列はカウント表の行見出しになります。

最初にパターンAとパターンBに出てくる文字をすべてリストアップしておくと、どの文字も同じ方法で数えられます。この文字の一覧を、この教材では「文字種マスター」と呼びます。

パターンAだけに出る文字、パターンBだけに出る文字が混ざっていても問題ありません。ある発話に出てこない文字は出現数 `0` として数えられるため、その発話の分布は変わりません。

まず、[文字種カウントツール]({{ '/20260511/count/?from=count-sheet' | relative_url }}) で「パターンAとB」を読み込み、文字種マスターを作ってください。

<a class="button-link" href="{{ '/20260511/count/?from=count-sheet' | relative_url }}">文字種カウントツールへ</a>

## 文字種マスターをA列に貼り付ける

`カウント` シートの `A4` セルを選択して、生成した文字一覧を貼り付けます。`A4` から下に文字が縦に並べば成功です。

## 関数を入れる: 発話ごとの出現数

`B4` セルに次の関数を入れます。

<div class="code-copy">
  <pre><code>=LEN(B$2)-LEN(SUBSTITUTE(B$2,$A4,""))</code></pre>
  <button type="button" class="small" data-copy="=LEN(B$2)-LEN(SUBSTITUTE(B$2,$A4,&quot;&quot;))">コピー</button>
</div>

この関数の意味は次のとおりです。

- `LEN(B$2)`: `B2` の発話の文字数
- `SUBSTITUTE(B$2,$A4,"")`: `B2` の中から `A4` の文字をすべて削除した文字列
- もとの長さから削除後の長さを引くと、その文字が何個あったか分かる

## なぜ `$` を付けるのか

- `B$2`: 列はコピー先に合わせて動くが、行は2行目のまま
- `$A4`: 行はコピー先に合わせて動くが、列はA列のまま

## オートフィルで広げる

1. `B4` セルを選択する
2. 右下の小さい四角を `H4` までドラッグする
3. `B4:H4` を選択して、`H142` まで下にドラッグする
4. `B4` をコピーして `O4` に貼り付ける
5. `O4` セルを `U142` までオートフィルする

## 視点2のために: 会話全体の出現数を計算

発話ごとの出現数ができたら、会話全体の出現数を作ります。

パターンAは `I4:N4` に、1発話目からの累積範囲の出現数を作ります。

| セル | 関数     | 意味        |
| ---- | -------- | ----------- |
| `I4` | `=B4+C4` | Aの発話1〜2 |
| `J4` | `=I4+D4` | Aの発話1〜3 |
| `K4` | `=J4+E4` | Aの発話1〜4 |
| `L4` | `=K4+F4` | Aの発話1〜5 |
| `M4` | `=L4+G4` | Aの発話1〜6 |
| `N4` | `=M4+H4` | Aの発話1〜7 |

パターンBは `V4:AA4` に、同じように累積範囲の出現数を作ります。

| セル  | 関数     | 意味        |
| ----- | -------- | ----------- |
| `V4`  | `=O4+P4` | Bの発話1〜2 |
| `W4`  | `=V4+Q4` | Bの発話1〜3 |
| `X4`  | `=W4+R4` | Bの発話1〜4 |
| `Y4`  | `=X4+S4` | Bの発話1〜5 |
| `Z4`  | `=Y4+T4` | Bの発話1〜6 |
| `AA4` | `=Z4+U4` | Bの発話1〜7 |

<div class="code-copy">
  <pre><code>=B4+C4</code></pre>
  <button type="button" class="small" data-copy="=B4+C4">I4をコピー</button>
</div>

<div class="code-copy">
  <pre><code>=I4+D4</code></pre>
  <button type="button" class="small" data-copy="=I4+D4">J4をコピー</button>
</div>

<div class="code-copy">
  <pre><code>=O4+P4</code></pre>
  <button type="button" class="small" data-copy="=O4+P4">V4をコピー</button>
</div>

<div class="code-copy">
  <pre><code>=V4+Q4</code></pre>
  <button type="button" class="small" data-copy="=V4+Q4">W4をコピー</button>
</div>

`I4:N4` と `V4:AA4` を、それぞれ142行目までオートフィルします。

## 合計を出す

`B143` セルに次の関数を入れます。

<div class="code-copy">
  <pre><code>=SUM(B4:B142)</code></pre>
  <button type="button" class="small" data-copy="=SUM(B4:B142)">コピー</button>
</div>

これを `AA143` まで横にオートフィルします。各列の合計が、その発話、または累積範囲の総文字数です。

## チェックポイント

句読点を除くと、次の値に近くなります。

| セル    | 意味                | 参考値 |
| ------- | ------------------- | -----: |
| `B143`  | パターンAの発話1    |   `28` |
| `N143`  | パターンAの発話1〜7 |  `197` |
| `O143`  | パターンBの発話1    |   `25` |
| `AA143` | パターンBの発話1〜7 |  `183` |

合わない場合は、次を確認します。

- 文字一覧に句読点や空白が混ざっていないか
- `$` の位置が間違っていないか
- 発話を `B2:H2` に貼れているか
- 発話を `O2:U2` に貼れているか
- 文字一覧を `A4` から貼れているか

これで、パターンAとパターンBの出現数が同じシートにそろいました。
