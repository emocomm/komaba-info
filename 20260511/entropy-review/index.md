## 平均情報量とは

平均情報量、またはエントロピーは、ある情報源から出てくる記号の「散らばり具合」を表す量です。式は次のとおりです。

<div class="code-copy">
  <pre><code>H = -Σ p(x) log₂ p(x)</code></pre>
  <button type="button" class="small" data-copy="H = -Σ p(x) log₂ p(x)">コピー</button>
</div>

- `p(x)` は、記号 `x` が出る確率
- 単位は `bit`
- すべての記号が等確率で出るとき、`H` は大きくなる
- ある記号だけが出るとき、`H = 0`

## 直感的な例

| 文字列                 | 状態       | 平均情報量            |
| ---------------------- | ---------- | --------------------- |
| `ああああああああああ` | すべて同じ | `0 bit`               |
| `あいうえおかきくけこ` | すべて違う | `log₂(10) ≒ 3.32 bit` |

散らばりが大きいほど、平均情報量は大きくなります。

## 今回覚えておくこと

平均情報量は、ある情報源、つまり「記号の出方の分布」に対して定義される量です。

同じ文字列でも、どこからどこまでを「ひとつの情報源」とみなすかによって、平均情報量は変わります。これは今回の課題で重要になります。
