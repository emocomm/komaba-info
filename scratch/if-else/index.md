ここからはScratchを使って、アルゴリズムの基礎（条件分岐・繰り返し・リスト）を学びます。前のページまでで覚えたブロックの並べ方を土台に、プログラムの「考え方」を順番に確かめていきます。

If else文は、プログラムが特定の条件を満たした場合にのみ特定のコードを実行するために使用されます。条件が真（True）であればif文の中のコードが実行され、条件が偽（False）であればelse文の中のコードが実行されます。

例えば、テストの点数によって合格か不合格かを表示するためのプログラムを書くためには、条件分岐が必要です。

<img class="guide-image" src="{{ '/assets/scratch/if-else-flow.svg' | relative_url }}" alt="条件分岐の流れ図：点数を入力 → 50点未満なら『不合格！』、そうでなければ『合格！』と話す">

上の図のように、条件分岐は「**ある条件を満たすかどうかで、進む道が枝分かれする**」という構造です。今回は「点数 < 50 か？」という条件で道を2つに分けています。

Scratchで条件分岐をするためには、「制御」カテゴリーの「もし　なら　でなければ」というブロックを使います。

Scratchで条件を満たしているかを調べるためには、「演算」カテゴリーの「 &gt; 」ブロックなどを使います。

<div class="callout">
  <strong>やってみよう</strong>
</div>

Scratchを使って、

1. テストの点数をネコが聞いて、あなたが答える
2. 点数が50点未満なら、ネコが「不合格！」と話す
3. 点数が50点以上なら、ネコが「合格！」と話す

と言う処理をするプログラムを書いてみましょう。
