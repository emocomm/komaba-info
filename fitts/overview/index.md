## 目的

フィッツの法則を理解し、その応用を学ぶことが目的です。実際に参加者としてフィッツの法則を確認するための実験を体験し、その結果をもとにレポートを書いてください。

## 概要

フィッツの法則は、ターゲットに到達する時間が、ターゲットまでの距離とターゲットの大きさに依存することを示しています。式は次のとおりです。

<div class="code-copy">
  <pre><code>T = a + b · log₂(D / W + 1)</code></pre>
  <button type="button" class="small" data-copy="T = a + b · log₂(D / W + 1)">コピー</button>
</div>

- `T`：到達時間
- `D`：ターゲットまでの距離
- `W`：ターゲットの幅
- `a`・`b`：実験で得られる定数

法則の意味をまだ確認していない場合は、先に「<a href="{{ '/fitts/about/' | relative_url }}">フィッツの法則とは</a>」を読んでください。

## 今回の実験の工夫：学生証でキャリブレーション

<div class="callout warn">
  <strong>今回は人によって使うパソコンが違います。</strong><br>
  同じ「<code>300px</code>」でも、画面の解像度や大きさが違えば、実際の長さ（cm）は端末ごとに変わってしまいます。これでは、集めたクリック時間を皆で比べられません。
</div>

そこで今回は、距離（D）とターゲットの大きさ（W）を、ピクセルではなく **ミリメートル（mm）** で指定します。実験を始める前に、**学生証** を使って「画面上の1mmが何ピクセルにあたるか」を測る **キャリブレーション** を行います。誰の端末でも、画面上の四角を学生証（縦54mm×横85.6mm）にぴったり合わせることで、`D` と `W` の実際の長さがそろい、どの端末でも同じ条件で実験できます。

このキャリブレーションを行ったこと自体も、あとでレポートの「実験条件・手順」に書いてもらいます。

## 全体の流れ

1. **実験の手順** — 学生証でキャリブレーションし、実験ツールで `D`・`W` を変えながらクリック時間を測る
2. 集めたデータ（`D`・`W`・`T`）を表計算ソフトに入力する
3. **分析の手順** — 困難指数 `ID` を自分で計算し、回帰分析でパラメータ `a`・`b` を求める
4. `ID` と `T` の関係を散布図にし、近似直線を引く
5. **レポート要件** — 実験条件・グラフ・考察・応用例をレポートにまとめてUTOLに提出する
