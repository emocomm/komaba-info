以下の項目に沿ってレポートを作成してください。形式はA4で1〜2枚程度です。

## 1. 実験条件・実験参加者・実験の手順

- **実験条件**：実験場所、使用したデバイス（PCの種類・画面の大きさなど）
- **実験参加者**：参加者数、属性（年齢、性別など）
- **実験の手順**：実験の流れを具体的に説明してください。

<div class="callout warn">
  <strong>キャリブレーションの方法も必ず書いてください。</strong><br>
  今回は端末ごとの画面サイズの違いをそろえるために、<strong>学生証（縦54mm×横85.6mm）を使って画面上の四角の大きさを合わせ、1mmあたりのピクセル数を求める</strong>キャリブレーションを行いました。なぜこの作業が必要だったのかも含めて、手順の中で説明してください。
</div>

## 2. 作成したグラフ

- 表計算ソフトで作成した「**困難指数（ID）とクリック時間（T）の関係**」のグラフを添付してください。
- グラフのタイトルと軸のラベルを適切に設定してください。

## 3. グラフの考察

- 作成したグラフをもとに、フィッツの法則に関する考察を行ってください。
- **困難指数がクリック時間に与える影響** について説明してください（ID が大きくなると T はどう変化したか）。
- 回帰分析の結果から得られた **パラメータ `a` と `b` の値を記載** し、それぞれが何を意味するのかを説明してください。

<div class="callout">
  考察のヒント：データ点は直線にどれくらいよく乗りましたか。乗らなかった点があれば、その原因（疲れ、慣れ、狙いの外れなど）は何だと考えられますか。`a` と `b` の値は直感と合っていますか。
</div>

## 4. 応用例の考察

- フィッツの法則が、実際のインターフェース設計や他の応用分野でどのように利用されるかを考察してください。
- 「<a href="{{ '/fitts/about/' | relative_url }}">フィッツの法則とは</a>」で触れた例（端や角の利用、右クリックメニュー、ボタンの大きさなど）も手がかりにして、自分の身のまわりのUIを1つ取り上げて説明すると書きやすいです。

## 提出方法

作成したレポートは、**UTOL** からアップロードしてください。

- レポートはPDF形式で、ファイル欄に添付してください。
- 作成したグラフを必ず含めてください。

## 採点ポイント

- 実験条件・手順（キャリブレーションの説明を含む）が具体的に書けているか
- グラフが見やすく、タイトルと軸ラベルが適切か
- ID と T の関係、および `a`・`b` の意味を自分の言葉で説明できているか
- 応用例の考察が、フィッツの法則と結びついているか
