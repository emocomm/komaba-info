実験で取得したデータを分析することで、フィッツの法則が実際に当てはまっているかを確認します。データは、1列目から **距離（D）・大きさ（W）・クリック時間（T）** の順に並んでいるものとして進めます（`A`列=D、`B`列=W、`C`列=T）。困難指数（ID）は、このページで自分で `D`列 に計算します。

## 1. 困難指数（ID）を計算する

困難指数 `ID` は、次の式で計算します。

<div class="code-copy">
  <pre><code>ID = log₂(D / W + 1)</code></pre>
  <button type="button" class="small" data-copy="ID = log₂(D / W + 1)">コピー</button>
</div>

実験ツールは困難指数（ID）を計算しません。ここで、表計算ソフトを使って自分で計算します。`A2` に距離（D）、`B2` に大きさ（W）が入っている場合、`D2` セルに次の数式を入力します。

<div class="code-copy">
  <pre><code>=LOG(A2/B2 + 1, 2)</code></pre>
  <button type="button" class="small" data-copy="=LOG(A2/B2 + 1, 2)">コピー</button>
</div>

この数式を `D`列 のデータの全行にコピーします。`LOG(値, 2)` は「2を底とする対数」という意味です。これで `D`列 に、各行の困難指数（ID）が並びます。

## 2. 線形回帰でパラメータ a・b を求める

フィッツの法則 `T = a + b · ID` の定数 `a`・`b` を、線形回帰で求めます。

1. Excelの「**データ**」タブ →「**分析ツール**」を開きます。表示されていない場合は、「ファイル」→「オプション」→「アドイン」から「分析ツール」を有効にしてください。
2. 「**回帰分析**」を選び、「OK」を押します。
   1. 「**入力 Y 範囲**」に、クリック時間（T）の範囲を入れます（例：`=Sheet1!$C$2:$C$11`）。
   2. 「**入力 X 範囲**」に、困難指数（ID）の範囲を入れます（例：`=Sheet1!$D$2:$D$11`）。
   3. 「**出力オプション**」は「新規ワークシート」を選びます。
3. 「OK」を押して分析を実行します。

<div class="callout">
  範囲の行数は、自分の実験回数に合わせて変えてください（例：実験を7回行ったなら <code>$C$2:$C$8</code>）。
</div>

<div class="callout warn">
  Googleスプレッドシートを使う場合は、<code>=INTERCEPT(C2:C11, D2:D11)</code> で <code>a</code> を、<code>=SLOPE(C2:C11, D2:D11)</code> で <code>b</code> を求められます。
</div>

## 3. パラメータを読み取る

回帰分析の結果（係数のセクション）から、次のように読み取ります。

- **切片（Intercept）** が、パラメータ `a`
- **X の係数（変数 X 1）** が、パラメータ `b`

`a` は ID が0に近いときの基本的な時間、`b` は困難指数が1増えるごとに増えるクリック時間を表します。

## 4. 散布図と近似直線を作る

1. データが入力された範囲を選択します。
2. リボンの「**挿入**」→「**散布図**」を選びます。
3. グラフを選択し、「**グラフのデザイン**」→「**データの選択**」で系列を編集します。
   - 「**系列 X の値**」に、困難指数（ID）の範囲（例：`=Sheet1!$D$2:$D$11`）
   - 「**系列 Y の値**」に、クリック時間（T）の範囲（例：`=Sheet1!$C$2:$C$11`）
4. 「**グラフのデザイン**」→「**グラフ要素を追加**」→「**近似曲線**」→「**その他の近似曲線オプション**」で「**線形近似**」を選びます。

## 5. グラフを仕上げる

- グラフのタイトル：「**クリック時間の変動**」
- 横軸のタイトル：「**困難指数（ID）**」
- 縦軸のタイトル：「**クリック時間（T）**」

必要に応じて、データ点にマーカーを付けるなど、見やすく整えます。近似直線の式（`y = b·x + a` の形）を表示すると、回帰分析で求めた `a`・`b` と対応していることが確認できます。

データとグラフがそろったら、「<a href="{{ '/fitts/report/' | relative_url }}">レポート要件</a>」に進んでください。
