実験で取得したデータを分析することで、フィッツの法則が実際に当てはまっているかを確認します。データは、1列目から **距離（D）・大きさ（W）・クリック時間（T）** の順に並んでいるものとして進めます（`A`列=D、`B`列=W、`C`列=T）。困難指数（ID）は、このページで自分で `D`列 に計算します。

<div class="callout warn">
  <strong>分析は Google スプレッドシートで行ってください。</strong><br>
  Excelの<strong>Web版（ブラウザ版）では回帰分析（分析ツール）が使えません</strong>。Googleスプレッドシートなら、関数だけで回帰分析ができます。どうしてもExcelで行いたい場合は、<strong>デスクトップ版のExcel</strong>を使ってください（各手順の下のアコーディオンに、Excelデスクトップ版のやり方を残してあります）。
</div>

## 1. 困難指数（ID）を計算する

困難指数 `ID` は、次の式で計算します。

<div class="code-copy">
  <pre><code>ID = log₂(D / W + 1)</code></pre>
  <button type="button" class="small" data-copy="ID = log₂(D / W + 1)">コピー</button>
</div>

実験ツールは困難指数（ID）を計算しません。ここで、スプレッドシートを使って自分で計算します。`A2` に距離（D）、`B2` に大きさ（W）が入っている場合、`D2` セルに次の数式を入力します。

<div class="code-copy">
  <pre><code>=LOG(A2/B2 + 1, 2)</code></pre>
  <button type="button" class="small" data-copy="=LOG(A2/B2 + 1, 2)">コピー</button>
</div>

入力したら、`D2` セルの右下の小さな四角（フィルハンドル）を下にドラッグして、データのある全行に数式をコピーします。これで `D`列 に、各行の困難指数（ID）が並びます。`LOG(値, 2)` は「2を底とする対数」という意味です。

## 2. 回帰分析でパラメータ a・b を求める

フィッツの法則は `T = a + b · ID` という直線の式です。この直線の **傾き `b`** と **切片 `a`** を求めることが「回帰分析」です。Googleスプレッドシートでは、次の3つの関数で求められます。空いているセル（例：`F1`〜`F3`）に入力してください。

**傾き `b`**（ID が1増えるとTがどれだけ増えるか）

<div class="code-copy">
  <pre><code>=SLOPE(C2:C11, D2:D11)</code></pre>
  <button type="button" class="small" data-copy="=SLOPE(C2:C11, D2:D11)">コピー</button>
</div>

**切片 `a`**（ID が0のときのTの値）

<div class="code-copy">
  <pre><code>=INTERCEPT(C2:C11, D2:D11)</code></pre>
  <button type="button" class="small" data-copy="=INTERCEPT(C2:C11, D2:D11)">コピー</button>
</div>

**決定係数 `R²`**（データが直線にどれだけよく乗っているか。1に近いほどよく当てはまる）

<div class="code-copy">
  <pre><code>=RSQ(C2:C11, D2:D11)</code></pre>
  <button type="button" class="small" data-copy="=RSQ(C2:C11, D2:D11)">コピー</button>
</div>

<div class="callout">
  <strong>引数の順番に注意。</strong> どの関数も <code>(クリック時間Tの範囲, 困難指数IDの範囲)</code> の順、つまり <strong>(縦軸Y, 横軸X)</strong> の順です。逆にすると違う値になります。<br>
  また、範囲の行数は自分の実験回数に合わせて変えてください。例えば実験を7回行ったなら <code>C2:C8</code> と <code>D2:D8</code> です。
</div>

<details>
  <summary>Excelデスクトップ版で回帰分析をする場合（クリックで開く）</summary>

  <p>Excelの<strong>デスクトップ版</strong>には「分析ツール」があり、回帰分析ができます（Web版では使えません）。</p>

  <ol>
    <li>「<strong>データ</strong>」タブ →「<strong>データ分析</strong>」を開きます。表示されていない場合は、「ファイル」→「オプション」→「アドイン」→「分析ツール」を有効にしてください。</li>
    <li>「<strong>回帰分析</strong>」を選び、「OK」を押します。
      <ul>
        <li>「<strong>入力 Y 範囲</strong>」に、クリック時間（T）の範囲を入れます（例：<code>$C$2:$C$11</code>）。</li>
        <li>「<strong>入力 X 範囲</strong>」に、困難指数（ID）の範囲を入れます（例：<code>$D$2:$D$11</code>）。</li>
        <li>「<strong>出力オプション</strong>」は「新規ワークシート」を選びます。</li>
      </ul>
    </li>
    <li>「OK」を押すと、結果が表示されます。「係数」の欄で、<strong>切片</strong> が <code>a</code>、<strong>X 値 1</strong> が <code>b</code> です。</li>
  </ol>
</details>

## 3. パラメータの意味

求めた `a`・`b` は、それぞれ次の意味を持ちます。レポートの考察で説明します。

- **`a`（切片）** … 困難指数 ID が0に近いときの基本的な時間。反応や準備にかかる時間にあたります。`a` の値は `=INTERCEPT(...)` で求めます。
- **`b`（傾き）** … 困難指数が1増えるごとに、クリック時間がどれだけ増えるか。動作の難しさへの「効きやすさ」で、グラフの直線の傾きとして見えます。

`R²` が1に近ければ、データがフィッツの法則の直線によく乗っている＝法則がよく当てはまっている、ということになります。

## 4. 散布図と回帰直線を作る

横軸を **困難指数（ID）**、縦軸を **クリック時間（T）** にした散布図を作り、回帰直線（近似直線）を1本重ねます。完成すると、次のようなグラフになります。

<img class="guide-image" src="{{ '/assets/fitts/regression-example.svg' | relative_url }}" alt="散布図の例。横軸が困難指数（ID, 2〜5）、縦軸がクリック時間（T）。データ点が右上がりに並び、その上に回帰直線が1本引かれている。">

点が右上がりに散らばり、その真ん中を1本の直線が通る形になれば成功です。点が直線の近くによく集まっているほど、フィッツの法則がよく当てはまっています。直線の **傾きが `b`** にあたります。

Googleスプレッドシートでの作り方は次のとおりです。

1. 困難指数（ID）の列（`D`）とクリック時間（T）の列（`C`）の、データの入っている範囲を選びます（見出しも含めてよいです）。
2. 「**挿入**」→「**グラフ**」を選びます。右側に「**グラフエディタ**」が開きます。
3. 「**設定**」タブで、「**グラフの種類**」を「**散布図**」にします。
4. 同じ「設定」タブで、軸を次のように指定します（横軸がID、縦軸がTになるように。逆になっていたら直します）。
   - 「**X 軸**」… 困難指数（ID）の列
   - 「**系列**」… クリック時間（T）の列
5. 「**カスタマイズ**」タブ →「**系列**」を開き、「**トレンドライン**」にチェックを入れます。種類は「**線形**」を選びます。
6. 同じ「系列」の中で、「**ラベル**」は「**なし**」にします。

## 5. グラフのタイトルと軸ラベルを整える

「**カスタマイズ**」タブ →「**グラフと軸のタイトル**」で、次を設定します。

- グラフのタイトル：「**クリック時間の変動**」
- 横軸（**横軸のタイトル**）：「**困難指数ID**」
- 縦軸（**縦軸のタイトル**）：「**クリック時間T（ms）**」

<details>
  <summary>Excelデスクトップ版でグラフを作る場合（クリックで開く）</summary>

  <ol>
    <li>データ範囲を選び、「<strong>挿入</strong>」→「<strong>散布図</strong>」を選びます。</li>
    <li>グラフを選択し、「<strong>グラフのデザイン</strong>」→「<strong>データの選択</strong>」で系列を編集します。
      <ul>
        <li>「<strong>系列 X の値</strong>」に、困難指数（ID）の範囲（例：<code>$D$2:$D$11</code>）</li>
        <li>「<strong>系列 Y の値</strong>」に、クリック時間（T）の範囲（例：<code>$C$2:$C$11</code>）</li>
      </ul>
    </li>
    <li>「<strong>グラフのデザイン</strong>」→「<strong>グラフ要素を追加</strong>」→「<strong>近似曲線</strong>」→「<strong>その他の近似曲線オプション</strong>」で「<strong>線形近似</strong>」を選びます。「数式を表示する」「R-2 乗値を表示する」にもチェックを入れると、式と決定係数が出ます。</li>
    <li>グラフタイトルを「クリック時間の変動」、横軸を「困難指数ID」、縦軸を「クリック時間T（ms）」にします。</li>
  </ol>
</details>
